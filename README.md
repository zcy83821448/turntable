# OHM DECK · 唱片机

一个单页的三维唱片机。模型在 Blender 里建模、导出 glTF 内联进页面，材质、灯光、后期、界面全部由代码生成，运行时零网络请求。

**在线看** <https://zcy83821448.github.io/turntable/> · **本地看** `node build.mjs`，然后双击 `index.html`（`file://` 下也正常）。

页面开机是一盘**空带**：转盘在转、传输条自己在走，点 **ADD MUSIC**（或把音频文件拖到页面上）放自己的曲子。仓库里不带任何音乐。

拖动转视角，滚轮缩放；`F` 开合防尘盖，`SPACE` 落针，`P` 打一张逐遍性能表，其余快捷键见页脚。

想读每个决定的理由和测量数字（three.js 的坑、幽灵部件、盖子反射、帧预算），看 [`NOTES.md`](NOTES.md) —— 那本来是这份 README。
